# StreamPulse v1.1.0-beta.1

First beta of the 1.1 feature update.

## New in this beta

- Russian and English interface and overlay text.
- Clean, Dark, Minimal, Neon, Classic and Glass themes.
- Fade and Float animations.
- Waiting music with local audio file selection and volume control.
- Optional countdown sound for the last 10 seconds.
- Optional stream-start sound at 00:00.
- Separate volume controls for music and sounds.
- Quick 10-second test mode.
- Custom warning and post-countdown text.
- Existing local image/video background support remains available.

## OBS

Use `start.html` as the visible Browser Source. The beta control panel is `admin-beta.html` and should not be shown in the final scene.

## Notes

This is a beta release. Test the new audio and localization features before using them on a live stream. Audio files and backgrounds are stored locally in the browser and are not included in the repository.
