# StreamPulse v1.1.0-beta.2 — Beta 2

Beta 2 expands the visual and audio customization introduced in Beta 1.

## New in Beta 2

- Fade, Float, Slide, Zoom and Glow animations.
- Overlay element-size control.
- Overlay block opacity control.
- RU/EN admin labels and overlay text.
- Waiting music with volume control.
- Optional last-10-seconds tick sound.
- Optional stream-start sound.
- Independent audio volumes.
- 10-second test mode.
- Reset timer control.
- Reset all local settings and audio/background data.

## OBS

1. Open `admin-beta2.html` in a browser.
2. Configure the language, theme, animation, text, background and audio.
3. Save or start the timer.
4. In OBS, use `start.html` as a Browser Source.
5. Keep the admin panel out of the final stream scene.

All settings and uploaded media are stored locally in the browser using Local Storage and IndexedDB. No external server is required.
