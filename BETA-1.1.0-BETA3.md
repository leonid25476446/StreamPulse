# StreamPulse v1.1.0-beta.3

Third beta build of the 1.1 release line.

## New in Beta 3

- Live admin preview for layout and visual settings.
- Horizontal and vertical position controls.
- Improved overlay scaling and positioning.
- Smooth waiting-music fade-out before the stream starts.
- Dedicated `admin-beta3.html` admin panel.
- RU/EN interface remains available throughout the beta.

## Testing focus

- Verify the preview matches the OBS overlay settings.
- Test different horizontal and vertical positions.
- Test all themes and animations.
- Test music, tick sound and start sound.
- Test the 10-second mode and the normal countdown.
- Verify the final transition at `00:00`.
- Verify OBS Browser Source behavior.

This is a pre-release build and is not the stable 1.1 release.
