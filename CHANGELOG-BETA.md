# Beta changelog

## 1.1.0-beta.1

### Added
- RU/EN localization for the beta admin panel and overlay.
- Six visual themes: Clean, Dark, Minimal, Neon, Classic and Glass.
- Fade and Float animation modes.
- Waiting music from a local audio file.
- Last-10-seconds countdown sound.
- Stream-start sound at 00:00.
- Independent audio volume controls.
- 10-second test mode.
- Custom warning and post-countdown messages.

### Preserved
- Local background image/video support.
- 30-second video limit.
- 120 MB video file limit.
- OBS Browser Source workflow.
- Local browser storage.
