# Beta changelog

## 1.1.0-beta.2

### Added
- Five animation modes: Fade, Float, Slide, Zoom and Glow.
- Element size control for the overlay.
- Overlay block opacity control.
- Full RU/EN labels for the Beta 2 admin panel.
- Reset timer and reset all settings controls.
- Separate Beta 2 admin panel: `admin-beta2.html`.
- Local tick and stream-start sound file support in the Beta 2 admin panel.

### Preserved
- RU/EN localization for the overlay.
- Six visual themes: Clean, Dark, Minimal, Neon, Classic and Glass.
- Waiting music from a local audio file.
- Independent audio volume controls.
- 10-second test mode.
- Custom warning and post-countdown messages.
- Local background image/video support.
- OBS Browser Source workflow.
- Local browser storage.

## 1.1.0-beta.1

### Added
- RU/EN localization for the beta admin panel and overlay.
- Six visual themes: Clean, Dark, Minimal, Neon, Classic and Glass.
- Fade and Float animation modes.
- Waiting music from a local audio file.
- Last-10-seconds countdown sound.
- Stream-start sound at 00:00.
- Independent audio volume controls.
- 10-second test mode.
- Custom warning and post-countdown messages.

### Preserved
- Local background image/video support.
- 30-second video limit.
- 120 MB video file limit.
- OBS Browser Source workflow.
- Local browser storage.
