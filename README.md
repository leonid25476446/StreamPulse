# StreamPulse

StreamPulse — локальный экран «Эфир скоро начнётся» для OBS с удобной админ-панелью.

## Возможности

- Таймер обратного отсчёта до 30 минут.
- Надпись «СКОРО ЭФИР» за 3 минуты до начала.
- Фото-фон с компьютера.
- Видео-фон до 30 секунд и до 120 МБ.
- Зацикливание видео.
- Четыре стиля: Clean, Pixel, Neon и Glass.
- Три режима анимации.
- Регулировка затемнения фона.
- Выбор цвета текста.
- Уведомления в админ-панели.
- Сохранение фонового файла через IndexedDB.
- Полностью локальная работа без сервера.
- Красивый экран для OBS без отображения админ-панели в эфире.

## Быстрый старт

1. Скачайте ZIP и распакуйте его целиком в обычную папку.
2. Откройте `admin.html` в Chrome или Edge.
3. Выберите фон.
4. Нажмите «Сохранить оформление».
5. Настройте таймер и нажмите «Запустить таймер».
6. Откройте OBS.
7. Добавьте «Источник браузера».
8. Включите «Локальный файл» и выберите `start.html`.
9. Установите размер источника под сцену, например 1920×1080.

### Важно

`admin.html` — только панель управления. В OBS добавляется только `start.html`, поэтому админ-панель не попадает в эфир.

Видео ограничено 30 секундами. При выборе файла админ-панель проверяет его длительность, а после сохранения дополнительно проверяет запись в IndexedDB.

Не запускайте HTML непосредственно из окна WinRAR. Сначала распакуйте ZIP.

## Приватность

StreamPulse не отправляет фон, настройки или другие данные на сервер. Всё работает локально в браузере.

## Для разработчиков

Проект не использует сборщик и внешние зависимости. HTML, CSS и JavaScript можно открыть напрямую.
