# StreamPulse

StreamPulse — локальный экран «Эфир скоро начнётся» для OBS с админ-панелью.

## v2 development build

В v2 проект расширяется до набора инструментов для стрима: отдельный чат Browser Source, TTS, награды, VIP, события, статистика, YouTube/Twitch и OBS-интеграция.

Сейчас в репозитории находится **development build v2**, а не финальный стабильный `v2.0.0`.

### Уже можно протестировать

- `start.html` — существующий экран Countdown для OBS.
- `admin.html` — существующая админ-панель Countdown.
- `chat-v2.html` — отдельный чат Browser Source для локального тестирования.
- `admin-v2.html` — локальная v2-панель для тестирования чата, TTS, ручных наград и событий.
- `V2-README.md` — статус разработки и план коннекторов.

### Быстрый тест v2

1. Распакуйте репозиторий в обычную папку.
2. Откройте `admin-v2.html` в Chrome или Edge.
3. Откройте `chat-v2.html` в отдельной вкладке.
4. Отправьте тестовое сообщение из v2 админки.
5. Проверьте, что оно появилось в `chat-v2.html`.
6. В OBS можно добавить `chat-v2.html` отдельным Browser Source.
7. `admin-v2.html` в сцену OBS не добавляется.

## Важное ограничение v2 development build

Локальный чат использует `BroadcastChannel`/`localStorage` для тестирования без сервера. Реальные подключения YouTube/Twitch, OAuth, live chat, постоянный учёт времени просмотра, production TTS, донаты и OBS WebSocket пока являются отдельными коннекторами и не должны считаться готовыми функциями стабильного релиза.

## v1 Countdown

- Таймер обратного отсчёта до 30 минут.
- Надпись «СКОРО ЭФИР» за 3 минуты до начала.
- Фото-фон с компьютера.
- Видео-фон до 30 секунд и до 120 МБ.
- Зацикливание видео.
- Стили Clean, Pixel, Neon и Glass.
- Анимации.
- Затемнение фона и цвет текста.
- Уведомления в админ-панели.
- Сохранение фонового файла через IndexedDB.
- Локальная работа без сервера.

## Приватность

Существующий Countdown работает локально. v2 development build не отправляет тестовые сообщения в YouTube или Twitch: внешние подключения появятся только после реализации и проверки соответствующих коннекторов.
